# Рабочая схема сайта «Не усложняй»

Сайт повторяет проверенную мобильную архитектуру сайта «Густой», но остаётся отдельным проектом в репозитории `nu-irk/nu-irk.github.io`.

## Структура

- `index.html` — общая страница без привязки к столу.
- `table-01/` … `table-12/` — самостоятельные страницы столов.
- На странице каждого стола кнопка счёта содержит прямую ссылку Netmonet и работает без JavaScript.
- `assets/nu-design-v3.webp` — лёгкий главный экран, предварительно загружаемый браузером.
- Основное и сезонное меню открываются в нативных полноэкранных `dialog` с вертикальной прокруткой.
- Первый лист основного меню загружается сразу, следующие листы — лениво.
- PDF остаются резервными ссылками.
- Информационное окно UDS присутствует на главной и каждой странице стола. Картинка загружается только при первом показе на устройстве, а кнопка «О бонусах» позволяет открыть окно повторно в любое время.

## Неизменяемые правила

1. Не объединять этот проект с сайтом «Густой» и не переносить файлы между репозиториями.
2. Не заменять отдельные страницы столов параметром выбора стола.
3. Не делать кнопку счёта зависимой от JavaScript.
4. Не возвращать тяжёлый PDF-просмотрщик или постраничную карусель меню.
5. После изменения `index.html` запускать генератор страниц столов.
6. После изменения ссылок или адресов страниц заново выпускать и распознавать QR-коды.

## Проверка перед публикацией

```text
node tools/verify-menu-viewer.mjs

```
